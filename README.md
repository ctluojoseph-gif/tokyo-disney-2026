# 東京小公主冒險手冊（繪本風 v4）

2026/11/3–11/7 東京家族旅行網站。

## 上傳到 GitHub Pages
1. GitHub 右上「＋」→ New repository → 名稱例如 `tokyo-2026` → Public → Create
2. 點 **uploading an existing file**，把 `index.html`、`README.md`、`.nojekyll`、整個 `files` 資料夾拖進去 → Commit changes
3. Settings → Pages → Branch 選 `main`、`/ (root)` → Save，1–2 分鐘後出現網址

（已經有 repo 的話：上傳新的 `index.html` 覆蓋舊檔即可。）

## 家人密碼
- 航班、住宿、雲端資料夾連結是加密的，要輸入家人密碼才看得到。
- 輸入一次後會記在那支手機，按住宿頁的「🔒 這支手機登出」可清除。
- 想換密碼：請 Claude 用新密碼重新產生 `index.html`（密碼不會以明文出現在檔案裡）。
- 這是前端加密，足以擋住一般路人，不是銀行等級的保護。機票和訂房單原檔仍然只在 Google 雲端，只有被加入共用的人打得開。

## 恢復舊版
舊版（v3）在「網站備份_v3_20261025.zip」裡，把裡面 `github/index.html` 上傳覆蓋即可恢復。
